# Сайт «Найди своё позиционирование»

Участник отвечает на открытые вопросы, нейросеть разбирает ответы и предлагает 3 варианта позиционирования: ближе к тому, что есть, смежный и смелый. Для каждого варианта есть темы, идеи роликов, формулировка и черновик шапки.

## Что в папке
- `index.html` — сам сайт.
- `api/analyze.js` — серверная функция, которая отправляет ответы в нейросеть. API-ключ хранится только тут, на сервере, и на сайт не попадает.
- `src/page.html` + `build.sh` — исходник страницы. Если правишь `src/page.html`, запусти `sh build.sh`, чтобы пересобрать `index.html`. Можно править и сразу `index.html`.

## Запуск на Vercel (бесплатно)
1. Получи API-ключ нейросети. Подойдёт любой OpenAI-совместимый сервис. Из России удобнее всего ProxyAPI (proxyapi.ru): оплата российской картой, работает как OpenAI. Базовый адрес сверь в их документации, обычно он такой: `https://api.proxyapi.ru/openai/v1`.
2. Залей эту папку на GitHub (новый репозиторий) или просто перетащи её в Vercel через `vercel deploy`.
3. На vercel.com: Add New → Project → выбери репозиторий → Deploy.
4. В проекте открой Settings → Environment Variables и добавь:
   - `LLM_API_KEY` — твой ключ
   - `LLM_BASE_URL` — адрес API, например `https://api.proxyapi.ru/openai/v1`
   - `LLM_MODEL` — модель для 3 вариантов, например `gpt-4o-mini` (дешёвая, тут справляется)
   - `LLM_MODEL_PACK` — модель для упаковки и контент-плана, например `gpt-4o` (поумнее, идеи заметно лучше)
   - `TG_BOT_TOKEN` и `TG_CHAT_ID` — чтобы ответы участников приходили вам в Telegram (как настроить, ниже)
5. Сделай Redeploy, чтобы переменные подхватились.
6. Подключи свой домен: Settings → Domains.

## Ответы участников в Telegram (сейчас выключено)
Если захотите видеть ответы участников, задайте переменные ниже. Перед этим верните на сайт поле «ник в Telegram» и предупреждение на первом экране, что ответы видят организаторы (попросите Claude, это 2 строки).
Каждый участник = 2 сообщения: все его ответы с вариантами, которые ему предложили, и какое направление он выбрал. Если участник оставил ник, он будет в сообщении.
1. В Telegram открой @BotFather → /newbot → придумай имя. Он пришлёт токен, это `TG_BOT_TOKEN`.
2. Создай группу (например «Анкеты МК»), добавь туда бота и напиши в группу любое сообщение.
3. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди там `"chat":{"id":-100...`. Это число (с минусом) и есть `TG_CHAT_ID`.
4. Добавь обе переменные в Vercel и сделай Redeploy.
Если переменные не заданы, сайт просто работает без отправки.

## Что поменять под себя
В начале скрипта в `index.html` есть блок `CONFIG`:
- `ctaUrl` — ссылка на твой Telegram или запись. Если заполнить, в конце разбора появится блок «Хочешь, чтобы мы разобрали твой профиль лично?». Текст блока меняется там же.
- `demo` — должен быть `false`. Если поставить `true`, сайт покажет пример разбора без запроса к нейросети.

Как нейросеть думает и пишет, задаётся в `api/analyze.js`, в тексте `SYSTEM`. Там можно поправить тон, правила и формат.

## Если что-то не работает
- «Не получилось сделать разбор»: проверь ключ, адрес и название модели в переменных окружения, потом сделай Redeploy. Ошибки видны в Vercel → проект → Logs.
- Одна попытка разбора — это один запрос к нейросети. На дешёвой модели это копейки, но если ссылка уйдёт в большой паблик, следи за балансом.
